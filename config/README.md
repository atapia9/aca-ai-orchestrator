# config

`sdda-servicios.yaml`: escalera de servicios SDDA — editable, no hardcodeada en el código. La carga y valida `@acambaro/core` (`cargarEscaleraServicios`, `packages/core/src/config/servicios.ts`).

Los precios con `estado: hipotesis` son hipótesis de negocio en validación, no precios publicados; la Propuesta debe marcarlos visiblemente (ver `packages/core/src/types/propuesta.ts`).
