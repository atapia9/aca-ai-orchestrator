# samples

Negocios ficticios de ejemplo para pruebas manuales y para `--manual`. Todos deben declarar `"ficticio": true` explícitamente — nunca datos de negocios reales.

- `negocio-ejemplo.json`: taller mecánico ficticio usado en el README y en `pnpm orchestrate diagnostico --manual samples/negocio-ejemplo.json`.

Los negocios ficticios de `evals/` (giros distintos, con criterios verificables) se agregan en la Fase 5.
